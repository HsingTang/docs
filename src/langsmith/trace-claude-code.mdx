The LangSmith tracing plugin sends your [Claude Code](https://code.claude.com/docs/en/overview) conversations to LangSmith so you can see what the agent did. Each message becomes a trace with its model calls, tool calls, skill calls, and subagents, and the messages from one session are grouped into a thread.

## Prerequisites

- [Claude Code](https://code.claude.com/docs/en/overview) installed.
- A LangSmith account.
- [Node.js](https://nodejs.org/) 20 or later on Windows and Linux. On macOS, the plugin runs its own build and does not need Node.js.

## Install the plugin

Run these commands inside Claude Code:

```bash
/plugin marketplace add langchain-ai/langsmith-claude-code-plugins
/plugin install langsmith-tracing@langsmith-claude-code-plugins
/reload-plugins
```

Auto-update is off for this marketplace by default. To turn it on, run `/plugin` and open **Marketplaces**.

To install the plugin for everyone in your organization, use Claude Code's managed settings. For more information, see [Manage Claude Code plugins for your organization](https://code.claude.com/docs/en/plugins/org).

## Sign in

Sign in once with the LangSmith CLI:

```bash
langsmith auth login
```

To use an API key instead, set `api_key` in your config file or `CC_LANGSMITH_API_KEY` in your environment. If your sign-in expires or your key is rejected, tracing pauses and Claude Code reminds you in the chat until you fix it. To refuse every prompt until the credentials work, turn on [strict auth](https://github.com/langchain-ai/langsmith-claude-code-plugins#strict-auth).

## Turn on tracing

Tracing is off until you turn it on in `~/.claude/langsmith.json`:

```json
{ "enabled": true, "project": "claude-code" }
```

Send a message and open the `claude-code` project in [LangSmith](https://smith.langchain.com). Each message appears as a trace, and the **Threads** tab groups a session's messages. To get a link to the current conversation's trace, run `/langsmith-tracing:trace`.

## Hide a conversation

To keep a conversation's content out of LangSmith, run `/langsmith-tracing:mute` inside Claude Code. Run `/langsmith-tracing:unmute` to turn full tracing back on. A muted conversation keeps its structure and token counts but leaves out what was said.

The confirmation appears as a prompt blocked by a hook, which is how Claude Code shows a plugin's reply. To mute every conversation by default, set `defaultMuted` to `true`.

## Secret redaction

The plugin redacts detected secrets from run inputs, outputs, errors, and metadata before uploading them to LangSmith. Redaction is on by default.

## Settings

Each setting has a config file key and an environment variable. The environment variable wins when both are set.

| Config key | Environment variable | Default | Description |
| --- | --- | --- | --- |
| `enabled` | `TRACE_TO_LANGSMITH` | `false` | Turns tracing on. |
| `api_key` | `CC_LANGSMITH_API_KEY` | none | LangSmith API key. Not needed if you sign in with the CLI. |
| `project` | `CC_LANGSMITH_PROJECT` | `claude-code` | Project the traces go to. |
| `api_url` | `LANGSMITH_ENDPOINT` | `https://api.smith.langchain.com` | LangSmith server to send to. |

For every setting, see the [plugin settings](https://github.com/langchain-ai/langsmith-claude-code-plugins#settings). To trace CI runs, nest traces under an existing run, or send traces to more than one project, see [Advanced configuration](https://github.com/langchain-ai/langsmith-claude-code-plugins/blob/main/ADVANCED.md).

## Troubleshooting

- **No traces**: Check that the plugin is enabled in `/plugin` and that tracing is on.
- **Tracing is paused**: Run `langsmith auth login` again or replace the rejected API key.
- **Still stuck**: Set `CC_LANGSMITH_DEBUG=true` and check `~/.claude/state/hook.log`.

For more fixes, see [When nothing shows up](https://github.com/langchain-ai/langsmith-claude-code-plugins#when-nothing-shows-up).
