[Claude Cowork](https://claude.com/docs/cowork/guide/plugins) runs the same plugins as Claude Code, so the [LangSmith tracing plugin for Claude Code](/langsmith/trace-claude-code) also traces Cowork tasks. Each turn becomes a trace with its model calls, tool calls, skill calls, and subagents, and the turns from one task are grouped into a thread.

## Prerequisites

- Access to Claude Cowork in the Claude desktop app.
- A LangSmith account.

## Install the plugin

Cowork installs plugins from your claude.ai account. To install the plugin for yourself:

1. Go to **Customize** > **Plugins** on claude.ai.
2. Add the `langchain-ai/langsmith-claude-code-plugins` repository as a marketplace.
3. Install the `langsmith-tracing` plugin from that marketplace.

The plugin loads into the next Cowork task you start. To install it for everyone in your organization, see [Choose a rollout route](https://claude.com/docs/plugins/org-rollout).

## Sign in and turn on tracing

Sign in once with the LangSmith CLI:

```bash
langsmith auth login
```

Then turn tracing on in `~/.claude/langsmith.json`, the same file Claude Code reads:

```json
{ "enabled": true, "project": "claude-cowork" }
```

To use an API key instead of the CLI sign-in, add it to the same file as `api_key`. For every other setting, see [Trace Claude Code applications](/langsmith/trace-claude-code).

## View traces in LangSmith

Start a Cowork task and open the project you configured. Each turn appears as a trace, and the **Threads** tab groups a task's turns. Skill calls record which skill ran, so you can filter traces by skill.
