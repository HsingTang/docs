The LangSmith tracing plugin sends your [OpenAI Codex](https://developers.openai.com/codex) sessions to LangSmith so you can see what the agent did. Each turn becomes a trace with its model calls, tool calls, and subagent threads, and the turns from one session are grouped into a thread.

## Prerequisites

- [Codex CLI](https://developers.openai.com/codex/quickstart?setup=cli) v0.153.4 or later.
- A LangSmith account.
- [Node.js](https://nodejs.org/) 22.x or later on Windows and Linux. On macOS, the plugin runs its own build and does not need Node.js.

## Install the plugin

Add the marketplace and install the plugin:

```bash
codex plugin marketplace add langchain-ai/langsmith-codex-plugins
codex plugin add tracing@langsmith-codex-plugins
```

Then trust the plugin's hooks with `/hooks` inside Codex, or when Codex's plugin UI asks. Nothing traces until you do, and `codex exec` skips the hooks until you have trusted them once.

ChatGPT workspace admins can install the plugin for everyone by importing the repository as a marketplace. For more information, see [Plugin management](https://developers.openai.com/codex/enterprise/plugin-management).

## Sign in

Sign in once with the LangSmith CLI:

```bash
langsmith auth login
```

To use an API key instead, set `api_key` in your config file or `LANGSMITH_CODEX_API_KEY` in your environment. If your sign-in expires or your key is rejected, tracing pauses and Codex shows a notice in the chat until you fix it. To refuse every prompt until the credentials work, turn on [strict auth](https://github.com/langchain-ai/langsmith-codex-plugins#strict-auth).

## Turn on tracing

Tracing is off until you turn it on in `~/.codex/langsmith.json`:

```json
{ "enabled": true, "project": "codex" }
```

Complete a turn and open the `codex` project in [LangSmith](https://smith.langchain.com). Each turn appears as a trace, and the **Threads** tab groups a session's turns.

## Hide a conversation

To keep a thread's content out of LangSmith, send `langsmith-tracing:mute` as a normal message with no leading slash. Send `langsmith-tracing:unmute` to turn full tracing back on. Muting applies from the next turn, so wait for the confirmation before you send anything sensitive.

The confirmation appears as a prompt blocked by a hook, which is how Codex shows a plugin's reply. To mute every thread by default, set `defaultMuted` to `true`.

## Secret redaction

The plugin redacts detected secrets from run inputs, outputs, errors, and metadata before uploading them to LangSmith. Redaction is on by default.

## Settings

Each setting has a config file key and an environment variable. The environment variable wins when both are set.

| Config key | Environment variable | Default | Description |
| --- | --- | --- | --- |
| `enabled` | `TRACE_TO_LANGSMITH` | `false` | Turns tracing on. |
| `api_key` | `LANGSMITH_CODEX_API_KEY` | none | LangSmith API key. Not needed if you sign in with the CLI. |
| `project` | `LANGSMITH_CODEX_PROJECT` | `codex` | Project the traces go to. |
| `api_url` | `LANGSMITH_CODEX_ENDPOINT` | `https://api.smith.langchain.com` | LangSmith server to send to. |

For every setting, see the [plugin settings](https://github.com/langchain-ai/langsmith-codex-plugins#settings). To send traces to more than one project, see [Send a trace to more than one place](https://github.com/langchain-ai/langsmith-codex-plugins#send-a-trace-to-more-than-one-place).

## Troubleshooting

- **No traces**: Check that the plugin is installed, its hooks are trusted with `/hooks`, and tracing is on.
- **Stopped after an update**: Codex asks you to trust a hook again whenever a release changes it. Run `/hooks` and approve it.
- **Tracing is paused**: Run `langsmith auth login` again or replace the rejected API key.

For more fixes, see [When nothing shows up](https://github.com/langchain-ai/langsmith-codex-plugins#when-nothing-shows-up).
