The LangSmith tracing plugin sends your [Cursor](https://cursor.com/) agent conversations to LangSmith so you can see what the agent did. Each prompt becomes a trace with its model calls, tool calls, skill reads, and subagents, and the prompts from one conversation are grouped into a thread.

## Prerequisites

- [Cursor](https://cursor.com/) installed.
- A LangSmith account.
- [Node.js](https://nodejs.org/) 22.13 or later on Windows and Linux. On macOS, the plugin runs its own build and does not need Node.js.

## Install the plugin

To install the plugin for yourself:

1. Open **Customize** in Cursor and choose **Add Marketplace**.
2. Enter `https://github.com/langchain-ai/langsmith-cursor-plugins`.
3. Run `/add-plugin langsmith-tracing` in the agent chat.
4. Fully restart Cursor so it loads the plugin's hooks.

Admins on a Teams or Enterprise plan can install the plugin for everyone by importing the repository as a team marketplace. For more information, see [Cursor's plugin docs](https://cursor.com/docs/plugins).

## Sign in

Sign in once with the LangSmith CLI:

```bash
langsmith auth login
```

To use an API key instead, set `api_key` in your config file or `LANGSMITH_CURSOR_API_KEY` in your environment. If your sign-in expires or your key is rejected, tracing pauses and the plugin writes the reason to `~/.cursor/langsmith_hook.log`, since Cursor cannot show a message without stopping the prompt. To hold back every prompt until the credentials work, turn on [strict auth](https://github.com/langchain-ai/langsmith-cursor-plugins#strict-auth).

## Turn on tracing

Tracing is off until you turn it on in `~/.cursor/langsmith.json`:

```json
{ "enabled": true, "project": "cursor" }
```

Send a prompt and open the `cursor` project in [LangSmith](https://smith.langchain.com). Each prompt appears as a trace, and the **Threads** tab groups a conversation's prompts. In Auto mode the model shows as `default` because Cursor does not report which model ran, and subagents show no token counts because Cursor does not report usage for them.

## Hide a conversation

To keep a conversation's content out of LangSmith, send `langsmith-tracing:mute` as a message in Cursor's agent chat. Send `langsmith-tracing:unmute` to turn full tracing back on. The message must be exactly that text with no slash, or it is traced as a normal prompt.

The acknowledgment appears as a blocked prompt, which is how Cursor shows a plugin's reply. To mute every new conversation by default, set `defaultMuted` to `true`.

## Secret redaction

The plugin redacts detected secrets from run inputs, outputs, errors, and metadata before uploading them to LangSmith. Redaction is on by default.

<CodingAgentSecretRedaction />

Images you attach to a prompt bypass redaction, so set `attachments` to `false` to stop sending them. To turn redaction off or add your own patterns, see the [plugin settings](https://github.com/langchain-ai/langsmith-cursor-plugins#settings).

## Settings

Each setting has a config file key and an environment variable. The environment variable wins when both are set.

| Config key | Environment variable | Default | Description |
| --- | --- | --- | --- |
| `enabled` | `TRACE_TO_LANGSMITH` | `false` | Turns tracing on. |
| `api_key` | `LANGSMITH_CURSOR_API_KEY` | none | LangSmith API key. Not needed if you sign in with the CLI. |
| `project` | `LANGSMITH_CURSOR_PROJECT` | `cursor` | Project the traces go to. |
| `api_url` | `LANGSMITH_CURSOR_ENDPOINT` | `https://api.smith.langchain.com` | LangSmith server to send to. |

For every setting, see the [plugin settings](https://github.com/langchain-ai/langsmith-cursor-plugins#settings).

## Troubleshooting

- **No traces**: Check that the plugin is in Cursor's plugin list, that you fully restarted Cursor after installing it, and that tracing is on.
- **Tracing is paused**: Run `langsmith auth login` again or replace the rejected API key.
- **Still stuck**: Run `tail -f ~/.cursor/langsmith_hook.log` while you send a prompt. Set `LANGSMITH_CURSOR_DEBUG=1` for more detail.

For more fixes, see [When nothing shows up](https://github.com/langchain-ai/langsmith-cursor-plugins#when-nothing-shows-up).
